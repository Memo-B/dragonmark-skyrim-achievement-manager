# Code of conduct

Treat contributors and users respectfully. Critique ideas constructively. Harassment,
threats, discrimination, doxxing and sharing credentials or account information are
unacceptable. Respect differing experience levels and backgrounds.

Maintainers may remove inappropriate content, close disruptive discussions and restrict
participation for repeated or serious violations. Enforcement should be proportionate,
documented privately and reconsidered when new evidence is available.

Report concerns privately using the maintainer's contact method on their GitHub profile.
Do not publish private evidence in an issue.
