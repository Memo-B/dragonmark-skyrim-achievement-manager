# Dragonmark naming decision

Research date: **2026-11-09**. Final identity: **Dragonmark · Skyrim Achievement Manager**. Repository slug: **dragonmark-skyrim-achievement-manager**. Executable: **Dragonmark.exe**. Internal `Dragonmark.*` assemblies and namespaces remain unchanged.

Dragonmark preserves the project's existing identity, is easy to say, and suggests a dragon plus an earned mark. The explicit subtitle carries the product purpose and search terms. It is **not an unused word**: an unrelated Clojure project already uses it, and Dragonmarks appear in Wizards of the Coast's Eberron material. We retain it as a qualified project identity, without claiming exclusivity, trademark clearance or universal availability.

## Evidence and limits

- [dragonmark/dragonmark](https://github.com/dragonmark/dragonmark): existing unrelated software use; inspected public project metadata only, not reused code.
- [Wizards of the Coast: Dragonmarks](https://media.wizards.com/2018/dnd/downloads/UA_Dragonmarks.pdf): official fantasy use of the term. No artwork or identity was copied.
- [Nordmark company code of conduct](https://nordmark.as/media/bovfwasz/nordmark-business-code-of-conduct.pdf): established company use. Repository search also returned [oldmarkdesigns/nordmark](https://github.com/oldmarkdesigns/nordmark).
- [Memo-B/dragonmark-skyrim-achievement-manager](https://github.com/Memo-B/dragonmark-skyrim-achievement-manager): existing public repository, empty when inspected, with no releases. This is a verified existing home, not a claim that an unregistered name is available.
- Searches included `Dragonmark in:name`, `DovahLedger in:name`, `Nordmark in:name`, `ThuumLedger in:name`, `SummitSigil in:name`, and exact-name web queries. Results are a dated sample, not an exhaustive trademark search.

No legal opinion, registry clearance, domain availability or future search position is asserted. Avoid official Skyrim/Steam marks in the original geometric icon and always identify the tool as independent. A legal review would be a separate task if distribution scope requires it.
